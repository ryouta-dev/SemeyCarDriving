# 🗺️ Roadmap: Semey Car Driving

Данный план разбит на этапы для последовательной и комфортной сборки проекта в режиме соло-разработки с ИИ (Vibe Coding).

## Фаза 1: Core Foundation (Ядро и Базовая Физика)
- [x] **Инициализация проекта:** Создание единого проекта Godot 4 в корневой папке (`c:\SemeyCarDriving v0.0.1`). Настройка рендера (Mobile/Vulkan), подключение Jolt Physics 3D, настройка Input Map (клавиатура + тач).
- [x] **Сборка физики авто (GEVP):** Интеграция ядра Godot-Easy-Vehicle-Physics. Настройка эталонного пресета управления (симкада с контррулением и сглаживанием ввода).
- [x] **Интеграция Pro-Vehicle-Camera:** Подключение кинематографичной камеры с эластичным следованием, FOV-искажением, эффектами тряски и круговым сенсорным обзором (Touch Orbit).
- [ ] **Базовый звук:** Подключение динамического звука двигателя (RPM Glide), звуков скольжения шин и ударов.
- [x] **Тестовый полигон:** Создание закрытой тестовой сцены с рампами и поворотами для калибровки физики "Камри" или "Приоры".

## Фаза 2: Mobile UI и Геймплейные Механики
- [x] **Мобильное управление:** Верстка и программирование экранных кнопок (Газ, Тормоз, Ручник, переключатель Стрелки/Руль, сенсорный поворот камеры по экрану, селектор AUTO/MAN, подрулевые лепестки +/-).
- [x] **Приборная панель (HUD):** Интеграция аналогового векторного тахометра, цифрового спидометра и индикатора передач (D/M режимы).
- [x] **Обратная связь (VFX):** Частицы дыма из-под колес при заносе (подключены в сцене).

## Фаза 3: Город Семей (OSM Environment)
- [x] **Парсер OSM:** Загружены реальные данные города Семей (`data/map.osm` 1.44 МБ — Подвесной мост, набережная Иртыша, центральные улицы) и интегрирован потоковый тайловый менеджер (`osm_tile_manager.gd`).
- [x] **Генерация дорог:** Процедурная генерация 3D-дорог со сглаживанием, полосностью, перекрестками, разметкой и шейдерами асфальта.
- [x] **Генерация строений:** Экструзия зданий по реальным контурам OSM с PBR-шейдерами стен/крыш и 3D-коллизиями (`ConvexPolygonShape3D`).
- [x] **Атмосфера и Погода:** Процедурный суточный цикл (день/ночь) с автоматическими уличными фонарями и фарами, переключение дождя/мокрого асфальта (горячие клавиши F5/F6 и экранные кнопки).
- [ ] **Интеграция кастомных моделей (Landmarks):** Подготовка конвейера для замены процедурных участков на ручные 3D-модели из Blender (например, Подвесной мост).

## Фаза 4: Живой Трафик (AI Traffic)
- [ ] **Дорожный граф:** Настройка навигационной сетки на основе сгенерированных OSM-дорог с учетом полосности и направлений.
- [ ] **Спавнер трафика:** Внедрение системы локального пулинга ботов вокруг игрока.
- [ ] **Поведение ИИ:** Настройка удержания полосы, торможения перед препятствиями и светофорами.
- [ ] **Шашки и Аварии:** Настройка физических реакций трафика на столкновения с игроком и регистрация "near miss" для системы Kudos.

## Фаза 5: Гараж и Тюнинг (Meta Gameplay)
- [x] **Сцена Гаража:** Интерактивный 3D Showroom (`scenes/garage.tscn`) с 3-точечным студийным светом, зеркальным подиумом и плавной орбитальной камерой (сенсорное вращение, зум, автоповорот).
- [x] **Стенс-тюнинг:** Полный набор регулировок подвески: клиренс перед/зад, развал (Camber) перед/зад с физической стабилизацией и визуальным наклоном колес, вылет колес (Offset / Track Width), жесткость подвески.
- [x] **Визуальный тюнинг:** Палитра трендовых авто-цветов, финиш (глянец / металлик / мат), тонировка стекол (от 0% до «бункера» 95%), покраска колесных дисков.
- [x] **Технический тюнинг:** Свап 4 моторов (Stock 2.5L 203hp, 3.5L V6 301hp, 2JZ-GTE Turbo 580hp, V8 Supercharged 750hp), выбор привода RWD (дрифт) / AWD (зацеп) и передаточных чисел главной пары.
- [x] **Сохранение прогресса:** Система профиля игрока (`ProfileManager`) с мгновенным автосохранением в `user://profile.json`, кнопкой «Сброс в сток», стартом игры из Гаража и кнопкой «ВЫЕХАТЬ В ГОРОД».

## Фаза 6: Полировка и Оптимизация (Подготовка к релизу)
- [ ] **Профайлинг (Mobile):** Замеры FPS на целевых устройствах, настройка LOD-ов для зданий и трафика.
- [ ] **Настройки графики:** Добавление меню управления качеством (тени, разрешение, дальность прорисовки, плотность трафика).
- [ ] **Мелкие фичи:** Эффекты отстрелов из выхлопа (Pops & Bangs), следы от шин (Skidmarks).
- [ ] **Сборка (Build):** Экспорт APK/AAB для Android и тест на реальном девайсе.
