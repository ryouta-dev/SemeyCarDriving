# Отчёт проверки 0.0.4

## Окружение

- Windows, Godot **4.7.2.stable** (`Godot_v4.7.2-stable_win64_console.exe`),
  export templates 4.7.2.
- Python 3.14 (запуск с `PYTHONUTF8=1`), без сети в момент прогонов.
- Android SDK/JDK отсутствуют → APK локально не собирался.

## Выполнено

### Python (57 проверок, OK)

```powershell
$env:PYTHONUTF8 = "1"
python -X utf8 -m unittest discover -s tests -p "test_*.py" -v
```

Покрытие: OSM-проекция и тайлы, внутренние полигоны, связи way/relation,
целостность GLB, ссылки на ресурсы, транзакции профиля, идемпотентность тюнинга,
мобильная раскладка, safe area, UID без исходников, отсутствие мёртвого кода,
покрытие реестра лицензий, наличие и размеры облегчённых моделей, выбор варианта.

### Godot: импорт

```powershell
godot --headless --path . --editor --import --quit
```

Exit code 0, в логе нет `SCRIPT ERROR`, `Parse Error`,
`Failed loading resource`, `Cannot open file`. Новые GLB импортированы,
`.import` и `.ctex` созданы.

### Godot: runtime (`tests/runtime_tests.gd`)

```
Runtime checks: 108; failures: 0
```

Проверено, в частности:

- валидация повреждённого профиля (цвет, жёсткость, двигатель, камера);
- раскладка на 4 разрешениях × 3 масштаба;
- идемпотентность тюнинга, покраска не меняет подвеску/инерцию;
- AWD/RWD пересобирает привод, свап обновляет сцепление;
- неизвестная поверхность → `Road`, дождь снижает сцепление;
- `owner` сброшен у `CustomBody` и всех четырёх `CustomWheel`;
- `high` → полная модель, `balanced`/`low` → облегчённая;
- после переключений вариантов ровно один `CustomBody`;
- гараж, город и полигон запускаются, машина активируется;
- меню ставит на паузу и снимает её; полигон работает без OSM-миникарты;
- `KudosTracker.reset_motion_state()` доступен.

Известное сообщение при выходе headless-процесса:
`12 RID allocations ... leaked at exit` — артефакт завершения тестового процесса
(сцены освобождаются перед `quit`), на игру не влияет; CI его не считает ошибкой.

## Не выполнено

- Сборка и установка APK/IPA, тест на реальном телефоне, FPS/память/нагрев.
- Визуальная проверка посадки колёс и интерьера на всех трёх авто.
- Профайлинг на большой карте.
- Проверка Android-джобы CI после пуша (workflow изменён).

## Как воспроизвести

См. [TESTING.md](TESTING.md). Для Windows обязателен `PYTHONUTF8=1`, иначе
Python читает исходники в cp1251 и часть проверок падает.
