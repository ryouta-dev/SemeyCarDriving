# Мобильный кандидат 0.0.3 — проверка перед APK / IPA

Это исходный проект, а не собранное приложение. Новый полный архив включает hotfix 01–04. Распаковать в отдельную папку, импортировать project.godot; старые hotfix поверх него НЕ применять.

## Новое управление
- Справа сверху **КАМЕРА**: ближняя → дальняя → салон → ближняя. Работает в городе и на полигоне.
- **МЕНЮ**: продолжить, испытания, раскладка, посадка в салоне, погода, освещение, миникарта, звук, вернуть машину, гараж. Длинное меню прокручивается пальцем.
- **Раскладка кнопок**: перетаскивать блоки, − / +, переключить руль/стрелки, сброс, готово. Игра при этом приостановлена. Сохраняется только секция HUD, а не старый снимок всего профиля.
- ГАЗ/ТОРМОЗ/РУЧНИК справа; рулевое управление слева. +/− передач скрыты в АКПП. Нижний переключатель АКПП/МКПП оставлен рядом с ручником.
- Геометрия использует единую систему координат, safe area и ограничение положения блоков. Вырез и системные поля учитываются через данные платформы; реальная корректность этих данных требует теста на телефонах.
- Формат игры — **горизонтальный**, оба направления. Портретная игра не поддерживается.

## Что проверить В ПЕРВУЮ ОЧЕРЕДЬ в Godot
1. Открыть свежую папку; дождаться чистого импорта без Parser Error / Script Error.
2. Запустить гараж, город и полигон. Проверить визуальную посадку колёс у всех трёх автомобилей: она всё ещё требует калибровки в движке, а не считается подтверждённой статической проверкой.
3. Проверить две стрелки + газ одновременно, газ + ручник, поворот камеры другим пальцем. Убрать палец за границу кнопки и отпустить: педаль не должна оставаться нажатой.
4. Нажать КАМЕРА трижды: все три вида переключаются. В салоне проверить посадку и прозрачность стёкол. Высота регулируется через меню, предел ±0.25 м.
5. Открыть меню на ходу: мир стоит, газ сброшен. Продолжить: движение возобновляется без залипания. Редактор раскладки также приостанавливает мир.
6. Свернуть и вернуть приложение, повернуть устройство в другое горизонтальное положение. Проверить «Продолжить», safe area, отсутствие add_child() busy-parent ошибки.
7. Меню: прокрутить до гаража, выключить миникарту/звук, перезапустить приложение и проверить сохранение.
8. В редакторе увеличить кнопки и попытаться вытащить их за края: они должны ограничиваться экраном и не перекрывать противоположную зону.
9. Запустить спринт/дрифт/парковку через меню. На полигоне доступны данные только для дрифта; остальные испытания сообщают, что нужна карта города.
10. Поставить качество Low, затем Balanced. Измерить FPS, память и нагрев после 10–15 минут езды/дождя/ночи. Старые устройства могут не поддерживать выбранный Mobile renderer.

## Команды проверки
Использовать движок и export templates одной версии (версия проекта/CI указана в основном README). Доступность конкретной сборки здесь не проверена.

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --audio-driver Dummy --script res://tests/runtime_tests.gd
PYTHONUTF8=1 python -X utf8 -m unittest discover -s tests -p 'test_*.py' -v
```

Runtime suite дополнен вызовами настоящей MobileLayout.controls и проверками меню. На 0.0.4 он выполнен на Windows: 108 проверок, 0 падений (`docs/TEST_REPORT.md`). На телефоне и в APK — ещё нет.

## Android APK
- Установить Android export templates, JDK/SDK, прописать пути в редакторе.
- Пресет Android: arm64, версия 0.0.3 / code 2; интернет и запись аудио не запрашиваются. Сначала экспортировать **debug APK**.
- Пользоваться одним debug keystore при обновлениях на том же телефоне. При смене подписи потребуется удаление старого приложения, а вместе с ним могут удалиться сохранения.
- Обычный запуск города без сети должен работать с включёнными в проект локальными OSM/GLB. Это должно быть подтверждено тестом в авиарежиме.
- release key, пароли и service credentials в архиве отсутствуют. Не публиковать debug сборку как релиз.

## iOS / IPA
- Пресет экспортирует **Xcode-проект ZIP**, не готовый IPA: build/ios/SemeyCarDriving-Xcode.zip; export_project_only=true.
- Для установки нужен macOS + Xcode, соответствующие iOS export templates, свой Bundle ID/Team, signing и provisioning под устройство.
- Указать свою Team в экспортном пресете, экспортировать проект, открыть его в Xcode, выбрать iPhone и запустить с корректной подписью. IPA для распространения формируется через Archive/Export после настройки подписи.
- Персональные сертификаты, Apple Team и provisioning profile пользователь добавляет у себя; они не включены в этот архив.
- Установка/подпись IPA без Xcode/Apple provisioning этим исходным ZIP не решается.

## Ограничение проверок
Офлайн-проверки геометрии используют Python-модель формул и контроль соответствия исходнику. Они НЕ проверяют настоящий Godot input routing, шрифты, iOS safe-area API, физику, компиляцию или производительность GPU. При ошибке отправить полный текст, модель телефона, ОС, версию Godot и сцену.
