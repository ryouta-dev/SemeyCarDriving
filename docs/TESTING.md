# План и команды тестирования

## 1. Автономные Python-проверки (без Godot и без сети)

```powershell
# Windows: без UTF-8 режима файлы читаются в cp1251 и часть тестов падает
$env:PYTHONUTF8 = "1"
python -X utf8 -m unittest discover -s tests -p "test_*.py" -v
```

Что покрыто: проекция OSM и отрицательные координаты, пересечение длинных дорог
с тайлами, внутренние полигоны, связи way/relation, целостность GLB, ссылки на
ресурсы, транзакционное сохранение профиля, идемпотентность тюнинга, мобильная
раскладка, наличие UID у каждого скрипта, отсутствие мёртвого кода, покрытие
реестра лицензий, два варианта модели.

Это статические проверки. Они **не** компилируют GDScript и не запускают игру.

## 2. Godot: чистый импорт

```powershell
# подставьте свой путь к Godot 4.7.2
godot --headless --path . --editor --import --quit
```

Нулевой код возврата не гарантирует отсутствие ошибок: проверьте лог на
`SCRIPT ERROR`, `Parse Error`, `Failed loading resource`, `Cannot open file`.
Первый импорт GLB и текстур занимает несколько минут.

## 3. Godot: runtime-проверки

```powershell
godot --headless --path . --audio-driver Dummy --script res://tests/runtime_tests.gd
```

Скрипт проверяет валидацию профиля, раскладку, идемпотентность тюнинга, AWD/RWD,
сцепление на мокрой дороге, `owner` у импортированных нод, переключение
high/low-вариантов, отсутствие дублей кузова, запуск гаража, города и полигона,
паузу меню и работу полигона без OSM-миникарты.

## 4. Ручной чек-лист

- [ ] Чистый импорт, гараж открывается, панель прокручивается на маленьком экране.
- [ ] Все три автомобиля: оси, колёса, посадка; возврат к Muscle без остатков.
- [ ] 20 раз изменить жёсткость и краску: подвеска не «закручивается».
- [ ] Переключить качество high → balanced → low: модель меняется, FPS растёт.
- [ ] Перезапуск сохраняет тюнинг, HUD, камеру, машину, качество, кредиты.
- [ ] Газ/руль отпущены после ухода пальца за кнопку, фона и смены режима.
- [ ] Поворот телефона, вырез, safe area.
- [ ] Выход в гараж во время загрузки не оставляет висящих нод/ошибок.
- [ ] День/ночь, дождь, сцепление, фары и фонари.
- [ ] Спринт/парковка/дрифт начисляют награду только за завершение.
- [ ] Полигон: слалом, рампа, Dirt/Grass, мост.
- [ ] 10–15 минут езды на Android: FPS, память, температура, фон, multi-touch.
