## 2. Видение

**Одна фраза:** «Выехал на Приоре на мост через Иртыш, прогрел мотор, поймал свет — и захотелось сделать ещё круг».

**Столпы (в порядке приоритета):**

1. **Картинка.** Свет, воздух, материалы, композиция кадра. Игрок должен узнать Семей и захотеть скриншот.
2. **Звук.** Живой мотор, шины, ветер, вода. Тишина без музыки — часть атмосферы.
3. **Ощущение управления.** Парковочная точность на малой скорости, вес, руль, камера.
4. **Узнаваемость.** Подвесной мост, набережная, панельки на горизонте, Приора.

**Чего в M1 нет:** гонок, заданий, денег, магазинов, мультиплеера, пешего режима, тюнинга, полиции, трафика-симулятора.

## 3. Зона M1: мост и набережная

### 3.1 Реальная геометрия как референс

В `data/map.osm` есть мост:

- way `44080309`, `highway=trunk`, `bridge=yes`, **1141 м**, 3 полосы в каждую сторону;
- пешеходные дорожки по обе стороны (ways `1311757258/1311757259`, ~1157 м);
- координаты: 50.40502, 80.22197 → 50.41469, 80.22738.

Используем масштаб и пропорции как референс, но строим вручную: реальная геометрия моста в OSM — только осевые линии, без пилонов и вант.

### 3.2 Состав зоны

| Зона | Содержание | Размер |
|---|---|---|
| A. Левобережный подъезд | съезд, развязка-кольцо, парковка у набережной, старт игрока | ~250 × 250 м |
| B. Набережная | променад, парапет, фонари, деревья, лавки, вода | ~400 м вдоль реки |
| C. Мост | 2 пилона, ванты, балка жёсткости, 2×3 полосы, тротуары, ограждения, фонари | 1141 м |
| D. Правобережный съезд | съезд, смотровая площадка, разворот | ~200 × 200 м |
| E. Дальний фон | силуэт города: панельки, трубы, холмы (billboard/low-poly) | — |

Маршрут-витрина: **старт у набережной → выезд на мост → проезд по мосту → смотровая на правом берегу → разворот**. Один круг ≈ 2,5 км, 2–3 минуты спокойной езды.

### 3.3 Что строим сами, а что берём

| Объект | Решение |
|---|---|
| Мост: пилоны, ванты, балки, ограждения, фонари | Строим сами: модульные сегменты + PBR бетон/металл |
| Набережная: парапет, променад, лестницы | Строим сами из модулей |
| Вода Иртыша | Плоскость + шейдер (нормали, отражения, пена у берега) |
| Деревья, кусты, лавки, урны, фонари | CC0 (Poly Pizza / Quaternius / Kenney) + свои фонари |
| Дальний город | Low-poly блоки/биллборды, свои |
| Дорога, разметка, бордюры | Свои меши + шейдер асфальта (есть в 0.0.4) |
| Трафик | 6–10 простых машин на сплайнах + статичные у набережной |
| Пешеходы | Нет (вне M1) |

### 4.1 Палитра (из референса)

| Деньги (в M1 скрыты) | `#F2C230` |
| UI-панель | `#121417` @ 85–92% |
| UI-акцент | `#F2C230` |
| UI-успех | `#3F9B4F` |
| UI-опасность | `#E2453C` |

### 4.2 Свет и атмосфера

- **День (по умолчанию):** солнце 45–55° к горизонту, тёплый ключевой свет `#FFF1DC`, холодные тени, лёгкая дымка над водой, видимость 2–3 км.
- **Закат (пресет):** солнце 8–12°, тёплый контровой свет, включённые фонари, усиленный bloom, синий воздух в тенях.
- Постобработка: tonemap ACES, exposure 1.0, bloom 0.4–0.8, SSAO (high), SSR на воде и мокром асфальте (high), DOF только в меню/гараже, volumetric fog выключен днём, лёгкий на закате.
- Тени: 4 cascade, 2048 atlas (high) / 1024 (low), дистанция 300 м.
- Отражения: reflection probe на мосту/набережной + SSR; для воды — planar-подобный шейдер.

### 4.3 Композиция кадра

- Третье лицо: камера за крышей, высота 2,0–2,4 м, дистанция 5,2–6,0 м, FOV 62–68°, лёгкий наклон в поворотах.
- Салон: точка у водителя, FOV 70–75°, видимый руль, стойки, зеркала; без «капсулы».
- Мост снимаем с низкой камеры: пилоны уходят в небо, ванты — в перспективе.

### 4.4 UI-стиль (из референса)

- Тёмные полупрозрачные панели, радиус 12–16 px, тонкая светлая обводка.
- Жирный condensed-шрифт с кириллицей (Inter / Roboto Condensed, OFL/Apache).
- Крупные тач-зоны ≥ 88 px при 1080p, safe area.
- Иконки — линейные белые SVG, рисуем сами.
- Деньги/штрафы **не показываем** (экономики нет).

## 5. Автомобиль

**Priora** — герой M1. В модели уже есть салон: сиденья, панель, руль (`priora_steer_47`), педали, зеркала, стёкла. 112 146 треугольников, 34 материала, 10 текстур.

Что делаем:

- PBR-материалы: кузов (clearcoat, metallic), стёкла (прозрачность, отражения), хром, резина, салон (ткань/кожа).
- Эмиссия: стопы, габариты, поворотники, ближний/дальний (spot-фары + линзы).
- Номерной знак: своя текстура (казахстанский формат).
- Колёса: правильная ось вращения, руль через существующий rig.
- LOD: `priora_rigged_low.glb` (43 820) для balanced/low; полный — для high.
- Материалы интерьера не красятся вместе с кузовом (уже разделено в 0.0.4).

## 6. Физика и управление

### 6.1 Парковочная модель (отличие от 0.0.4)

0.0.4 заточена под дрифт: высокий countersteer, lateral grip assist, ручник для заноса. Для M1:

- Максимальная скорость 90 км/ч (мост), крейсерская 50–60.
- Разгон плавный, без «прыжка»; ограничение крутящего момента на низких оборотах.
- **Автомат P/R/N/D**: P — паркинг (тормоз зажат), R — задний, N — нейтраль, D — вперёд; переключение кнопками/селектором.
- **Creep**: в D машина ползёт 5–7 км/ч без газа; в R — 3–4 км/ч.
- **Brake hold**: на уклоне удерживает тормоз 2 с после отпускания.
- Руль: 540° lock-to-lock, speed-sensitive, возврат в центр.
- Подвеска: мягче текущей, ход 0,18–0,22 м, без «дрифт-пружин».
- Сцепление: высокое, срыв только при ручнике/резком газе.
- Ассистенты дрифта (countersteer/lateral assist) **выключены**.
- Ручник: фиксирует задние колёса, для парковки и разворота.

### 6.2 Камеры

- **Третье лицо:** spring arm + collision, плавное следование, FOV +4° на скорости, наклон в поворотах 2–3°.
- **Салон:** фиксированная точка, свободный обзор пальцем/мышью, возврат в центр.
- Переключение кнопкой HUD и клавишей C; запоминается в профиле.

### 6.3 Схемы управления

| Схема | Поворот | Газ/тормоз | Примечание |
|---|---|---|---|
| Руль | виртуальный руль | педали | по умолчанию |
| Стрелки | ← → | педали | проще всего |
| Наклон | гироскоп | педали | калибровка в настройках |

Чувствительность, размер и положение элементов — в настройках; сохраняются.

## 7. UI/UX

### 7.1 Экраны

1. **Главное меню:** Приора на подиуме, студийный свет, название, кнопки: Играть, Гараж, Автосалон, Настройки, Выход. Версия и дисклеймер об ассетах — мелким шрифтом.
2. **Гараж:** простая витрина смены трёх машин (Priora / Лада 2110 / Muscle): камера-орбита, кнопка «Выехать». Без категорий, цен и прокачки.
3. **Автосалон:** каталог-витрина трёх машин с характеристиками; покупки нет, кнопка «Скоро» (чтобы не была мёртвой). Решение обратимо.
4. **Настройки:** качество (3 пресета), камера, схема управления, чувствительность, раскладка, звук, язык (RU), сброс.
5. **Пауза:** продолжить, настройки, гараж, выйти в меню.

### 7.2 HUD

| Элемент | Позиция | Размер (1080p) |
|---|---|---|
| Пауза, камера | слева сверху | 96×96 ×2 |
| Спидометр + передача | справа сверху | Ø 220 |
| Миникарта | снизу по центру-слева | Ø 200 |
| Руль | слева снизу | 260×260 |
| Педали (тормоз/газ) | справа снизу | 110×180 / 120×220 |
| Ручник | справа, над педалями | 120×96 |
| Селектор P/R/N/D | справа, над ручником | 4 × 64 |
| Свет/поворотники/сигнал | справа сверху под спидометром | 3 × 64 |

- Виртуальный руль: рендерим **реальный руль Приоры** (`priora_steer_47`) в `SubViewport` 256×256 — это даёт «дорогой» вид без новых ассетов.
- Миникарта: своя отрисовка схемы моста/набережной (линии дорог, вода, машина-стрелка), без OSM-генератора.
- Все элементы масштабируются от safe area, как в 0.0.4.
