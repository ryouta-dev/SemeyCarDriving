# Что осталось / где нужна проверка

Этот файл — честный список ограничений 0.0.4. Проверки исходников не заменяют
импорт в Godot, playtest и сборку на устройстве.

1. **Устройство и сборка.** Локально APK/IPA не собирались: на машине нет
   Android SDK/JDK. Android debug-APK собирается в CI; установка, FPS, память,
   нагрев и поведение в фоне на реальном телефоне не проверены. Для iOS нужен
   macOS, Xcode, Team ID и provisioning — экспортируется только Xcode-проект.
2. **Производительность.** Два варианта модели снижают нагрузку (Lada:
   428 858 → 128 549 треугольников), но 35 материалов и 97 примитивов на кузов
   остаются высокими для мобильного GPU. Целевые 30/60 FPS не измерены;
   `balanced` рендерит в 0.9 от нативного разрешения.
3. **Автомобили.** Точки крепления колёс, масса, центр тяжести и коллайдеры —
   приблизительные. Нужна калибровка на полигоне (посадка колёс, клиренс,
   поведение на рампе) и визуальная проверка обоих вариантов модели.
4. **OSM.** Поддержаны не все multipolygon-случаи; крупные объекты принадлежат
   тайлу-центроиду; туннели не вырезают поверхность. Активная карта —
   фрагмент ~600 м (`data/triumph_600m.osm`); большая `data/map.osm` не подключена.
   DEM отсутствует — рельеф плоский (поддерживаемый fallback).
5. **Стриминг.** Парсинг тайлов в `WorkerThreadPool`, инстансинг и построение фич
   под бюджет 4 мс/кадр. Один тяжёлый объект всё ещё может превысить бюджет;
   отмена задачи ждёт завершения текущего парсинга. Профайлер на большой карте
   не запускался.
6. **Трафик.** Только прототип: 2–4 простых кузова на полилиниях, без полос,
   светофоров, перекрёстков и пешеходов. По умолчанию выключен.
7. **Геймплей.** Три коротких испытания и один тип улучшения (тормоза). Нет
   карьеры, глубокой экономики, достижений, ежедневных задач, мультиплеера.
8. **Локализация.** Строки интерфейса зашиты по-русски; переключения языка нет.
9. **Лицензии.** Права на модели Lada/Priora, окружение OSM Racer и часть
   звуков не подтверждены — статус RED в `docs/ASSET_LICENSES.md`. Публичный
   релиз блокируется чек-листом оттуда.
10. **История git.** `main` на GitHub заменён корневым коммитом 0.0.4: `.env`
    больше не достижим по refs, но GitHub может отдавать старые коммиты по SHA
    до сборки мусора. Токен нужно отозвать независимо от этого
    (см. `docs/SECURITY_NOTES.md`).

Следующий безопасный этап: чистый импорт → полигон → профилирование на телефоне →
замена/подтверждение прав на ассеты → расширение карты и карьеры.
