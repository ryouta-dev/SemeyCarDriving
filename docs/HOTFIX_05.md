# Hotfix 05 для мобильной версии 0.0.3

Исправлен синтаксис анонимного обработчика с match: теперь кнопки редактора используют именованный метод и bind(action). MobileLayout во всех потребителях загружается явно через preload под отдельным именем. Файл scripts/ui/mobile_layout.gd включён в патч.

Распаковать этот патч в корень проекта версии 0.0.3 — туда, где project.godot — с заменой файлов. Перезапустить редактор и дождаться сканирования файлов. Если редактор продолжает показывать старую ошибку регистрации классов, закрыть Godot, удалить только папку .godot в проекте и импортировать снова. Не удалять scripts или сохранения user://.

Этот патч предназначен для полного мобильного архива 0.0.3, не для исходного проекта и не для базовой 0.0.2.

Проверки здесь только офлайн/исходниковые. Godot-компиляция не выполнена: движок отсутствует. Ошибка match подтверждена по присланному логу; остальные сообщения могут быть каскадными, либо связаны с отсутствием/регистрацией helper-файла.
